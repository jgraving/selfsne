# Release 0.1.0 notes

**Version:** 0.1.0 — 2026-10-31

## Added
- Updated documentation and examples
- Public code exports for core modules
- Tests covering key functionality

## Highlights
- SelfSNE LightningModule with full training/validation/test/predict lifecycle
- LikelihoodRatioEstimator with configurable kernels, divergences, baselines
- 10 row-wise + 13 pairwise kernels
- 12+ divergence functions
- 9 baseline estimators
- KNN sampling with FIFO queue
- Neural network subpackage: attention, TCN, positional/patch embeddings, gated MLPs
- Data utilities, noise augmentation, priors, transformer encoder, LR scheduling
- Plotting utilities: PCAAlign, EmbeddingDensity, density colormaps, highest density contours

## Changed
- Lightning floor raised to 2.4

## Fixed
- AMP overflow handling
- Checkpoint loss configuration validation
